# AutoScan

Програма комп'ютерної діагностики автомобілів для macOS (OBD2 через адаптер ELM327). Повністю українською.

## Що вміє

- **Огляд** — марка, рік і VIN авто, протокол, лампа Check Engine, готовність систем самоперевірки, оберти / температура / напруга.
- **Помилки** — активні, очікувані й постійні коди з поясненням простими словами, серйозністю і найчастішими причинами. Стирання помилок.
- **Живі дані** — понад 35 параметрів датчиків з графіками в реальному часі.
- **Норма vs зараз** — тільки для знайдених помилок: як сигнал має виглядати, що датчик показує зараз і що це означає.
- **Бази авто** — вбудована база 224 загальних кодів + **каталог пакетів марок в інтернеті** (завантаження одним натисканням; програма сама пропонує пакет за VIN).
- **Журнал адаптера** — усі команди й відповіді, щоб розібратися з проблемами зв'язку.
- **Звіт** — збереження результатів діагностики в текстовий файл.

Підключення: **USB-кабель** (швидкість підбирається сама), **Wi‑Fi**, **Bluetooth** (BLE і класичний) і **демо-режим** з 8 різними авто та поломками.

## Встановлення

1. Завантажте `AutoScan.dmg` зі сторінки [Releases](../../releases/latest).
2. Відкрийте DMG і перетягніть AutoScan у «Applications».
3. Перший запуск: macOS попередить про неперевіреного розробника → «Системні параметри → Приватність і безпека» → «Усе одно відкрити».

Потрібна macOS 13 Ventura або новіша. Працює на Mac з Intel і Apple Silicon.

## Які авто підтримуються

Будь-які з OBD2: бензинові в Європі з 2001 року, дизельні з 2004 року, у США — з 1996 року. Старіші авто (без OBD2) цей протокол не підтримують.

## Збірка

DMG збирається автоматично в GitHub Actions при кожному оновленні гілки `main`.
Локально на Mac: `bash scripts/build_dmg.sh` → `dist/AutoScan.dmg`.

Структура:
- `Sources/AutoScanCore` — протокол ELM327/OBD2, розбір відповідей, база помилок, правила «норма vs зараз», демо-авто.
- `Sources/AutoScan` — інтерфейс (SwiftUI) і канали зв'язку (USB, Wi‑Fi, Bluetooth).
- `Tools/build_dtc_db.py` — генерація бази кодів українською.
- `Tests` — тести розбору відповідей і повного сеансу з демо-авто.

## Як додати нову марку в каталог

Допишіть марку в `Tools/build_packs.py`, запустіть `python3 Tools/build_packs.py` і викладіть зміни — пакет з'явиться в програмі в розділі «Бази авто → Пакети в інтернеті».

## Формат пакета марки

```json
{
  "id": "vag",
  "brand": "Volkswagen",
  "title": "VAG: заводські коди",
  "version": "1.0",
  "matches": ["Volkswagen", "Audi", "Skoda", "Seat"],
  "notes": "Примітки щодо діагностики.",
  "codes": [
    { "c": "P1234", "t": "Коротка назва", "d": "Пояснення", "r": ["Причина 1", "Причина 2"], "s": 2 }
  ]
}
```

`s` — серйозність: 1 — можна їздити, 2 — перевірити найближчим часом, 3 — серйозно.
